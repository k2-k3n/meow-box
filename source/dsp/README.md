# Meow Voice

Meow Voice 跟踪吉他单音的音高，合成一声喵叫。可以把喵声混进吉他原声，也可以加上呼噜声。

## 使用方法

1. 先在 Resona Box 上安装本音频包。
2. 安装并打开 Meow Box 1.1.10。
3. 在 App 界面使用上方和下方编码器控制音色与功能。

## 配套关系

- 音频包：`org.resona.creative.meow-box.voice`，版本 1.0.3
- App：`org.resona.creative.meow-box`，版本 1.1.10

旋钮的具体操作见 [Meow Box 使用说明](../README.md)。
